# /new-widget

Crea un widget reutilizable Flutter.

## Uso
```
/new-widget <feature> <widget-name>
```

## Ejemplo
```
/new-widget expenses debt-rule-selector
```

## Instrucciones
1. Leer `.claude/agents/frontend-flutter.md` para paleta y convenciones
2. Crear widget con soporte light/dark mode (Theme.of(context))
3. Usar AppColors, AppTextStyles
4. Montos siempre con DM Mono
5. Documentar parámetros con doc comments
